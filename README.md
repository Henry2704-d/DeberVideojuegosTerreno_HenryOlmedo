# Aldea en la Montaña - Unity

Proyecto desarrollado en Unity como práctica de creación y diseño de una escena 3D.

## Descripción

La escena representa una pequeña aldea ubicada al pie de una gran montaña.
El terreno fue diseñado y modificado utilizando las herramientas de Terrain
de Unity para crear diferentes elevaciones y una zona montañosa alrededor
de la aldea.

Para complementar el escenario se utilizaron assets de árboles y cabañas.
También se crearon personajes NPC utilizando formas simples, los cuales
muestran diferentes diálogos cuando el jugador se acerca.

## Características

- Terreno creado y modificado con las herramientas de Terrain de Unity.
- Montañas y diferentes elevaciones en el terreno.
- Texturas aplicadas al terreno.
- Árboles agregados mediante assets.
- Cabañas agregadas mediante assets.
- NPC creados utilizando cubos y formas simples.
- Sistema de diálogos al acercarse a los NPC.
- Movimiento del jugador mediante Character Controller.
- Cámara controlada mediante el movimiento del mouse.

## Controles

- W: Avanzar.
- S:Retroceder.
- A: Moverse hacia la izquierda.
- D: Moverse hacia la derecha.
- Mouse: Controlar la dirección de la cámara.

## Cómo ejecutar el proyecto

1. Descargar o clonar este repositorio.
2. Abrir Unity Hub.
3. Seleccionar **Add project from disk**.
4. Seleccionar la carpeta descargada del proyecto.
5. Abrir el proyecto en Unity.
6. Abrir la escena principal del proyecto.
7. Presionar **Play** para iniciar y recorrer la escena.
